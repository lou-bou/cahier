A1

A small dice game

Warm-up

Throw a fair die. You win 5 DA on a 6, win 1 DA on a 4 or a 5, and lose 2 DA on a 1, 2 or 3. X = your gain.

(a) P(X = −2)? (b) E(X)?

Show solution

Go back to the faces: X⁻¹(−2) = {1, 2, 3}, X⁻¹(1) = {4, 5}, X⁻¹(5) = {6}.

x−215
P(X = x)1/21/31/6

(a) P(X = −2) = 3/6 = 1/2.

(b) E(X) = (−2) × 1/2 + 1 × 1/3 + 5 × 1/6 = −1 + 2/6 + 5/6 = 1/6 ≈ 0.167 DA per throw.

A2

Is it a law?

Warm-up

Which of these tables is not a valid law of a random variable?

Show solution

The chances of a law must be ≥ 0 and add up to 1.

0.5 + 0.4 + 0.2 = 1.1 ≠ 1: values 1, 2, 3 with 0.5, 0.4, 0.2 is not a law.

The others add to 1: 0.2 + 0.5 + 0.3, 3 × 1/3, 0.9 + 0.1.

A3

Reading the distribution function

Standard

X has the law below. Compute (a) F(1.5), (b) P(1 ≤ X ≤ 2), (c) P(1 < X < 3).

x0123
P(X = x)0.10.30.40.2
F(x) = P(X ≤ x)
P(a ≤ X ≤ b) = F(b) − F(a) + P(X = a)
P(a < X < b) = F(b) − F(a) − P(X = b)
Show solution

(a) F(1.5) = P(X ≤ 1.5) = P(X = 0) + P(X = 1) = 0.1 + 0.3 = 0.4.

(b) Values 1 and 2 are both inside: 0.3 + 0.4 = 0.7. With F: F(2) − F(1) + P(X = 1) = 0.8 − 0.4 + 0.3 = 0.7.

(c) Only the value 2 is strictly between 1 and 3: 0.4. With F: F(3) − F(1) − P(X = 3) = 1 − 0.4 − 0.2 = 0.4.

A4

Mean and variance

Standard

X takes the values 0, 1, 2 with chances 1/4, 1/2, 1/4. Compute (a) E(X), (b) Var(X), (c) Var(3X − 2).

Var(X) = E(X²) − (E(X))²
Show solution

(a) E(X) = 0 × 1/4 + 1 × 1/2 + 2 × 1/4 = 1.

(b) E(X²) = 0 + 1 × 1/2 + 4 × 1/4 = 3/2. Var(X) = 3/2 − 1² = 1/2.

(c) Var(aX + b) = a² Var(X): 9 × 1/2 = 9/2 = 4.5. The −2 only shifts, it does not spread.

A5

Rules for E and Var

Warm-up

a and b are constants, X and Y random variables. Complete each rule.

1. Var(aX) =

2. E(aX + b) =

3. Var(X + b) =

4. E(X + Y) =

Show solution
  1. Var(aX) = a² Var(X): multiplying by a multiplies distances by a, so squared distances by a².
  2. E(aX + b) = a E(X) + b: the mean follows any linear change.
  3. Var(X + b) = Var(X): adding b moves every value the same way: no extra spread.
  4. E(X + Y) = E(X) + E(Y): always true, even when X and Y are not independent.
A6

Finding a density

Standard

X has density f(x) = c·x on [0, 2] and 0 elsewhere. Find (a) c, (b) P(X ≤ 1), (c) E(X).

∫ f = 1 · P(a ≤ X ≤ b) = ∫ₐᵇ f · E(X) = ∫ x f(x) dx
Show solution

(a) Total area 1: ∫₀² c x dx = c × 4/2 = 2c = 1, so c = 1/2.

(b) P(X ≤ 1) = ∫₀¹ x/2 dx = 1/4 = 0.25.

(c) E(X) = ∫₀² x × x/2 dx = (1/2) × 8/3 = 4/3 ≈ 1.333.

A7

One exact value

Warm-up

X is a continuous random variable with density f and distribution function F. What is P(X = 2)?

Show solution

For a continuous variable a single point has no area under f: P(X = 2) = 0.

f(2) is a height, not a chance; F(2) = P(X ≤ 2).

A8

A function of X

Challenge

X is uniform on [0, 1]. (a) Y = X³: what is P(Y ≤ 0.125)? (b) Z = 3X + 2: what is E(Z)?

Show solution

(a) Turn the condition on Y into one on X: X³ ≤ 0.125 ⇔ X ≤ 0.5. So F_Y(0.125) = P(X ≤ 0.5) = 0.5.

(b) Linearity: E(Z) = 3 E(X) + 2 = 3 × 1/2 + 2 = 3.5. (Z is uniform on [2, 5], whose middle is 3.5.)

B1

Which law?

Warm-up

For each variable, pick the law that models it.

1. Number of heads in 10 tosses of a fair coin.

2. Number of calls reaching a help desk in one hour, 4 per hour on average.

3. Number of die throws needed to get the first 6.

4. Number of women in a committee of 3 drawn at once from 5 women and 7 men.

5. The face shown by one throw of a fair die.

n fixed + independent → binomial · wait for 1st success → geometric · no replacement → hypergeometric · average count per period → Poisson
Show solution
  1. Number of heads in 10 tosses of a fair coin. Binomial: n = 10 independent trials, count the successes: B(10, 1/2).
  2. Number of calls reaching a help desk in one hour, 4 per hour on average. Poisson: a count in a fixed time with a known average: P(4).
  3. Number of die throws needed to get the first 6. Geometric: wait for the first success: G(1/6).
  4. Number of women in a committee of 3 drawn at once from 5 women and 7 men. Hypergeometric: draws without putting back from two groups: H(12, 3, 5).
  5. The face shown by one throw of a fair die. Uniform: 6 equally likely values: U{1, …, 6}.
B2

Guessing a quiz

Standard

A quiz has 4 questions, each with 3 choices and one right answer. A student guesses every answer at random. X = number of right answers.

(a) P(X = 2)? (b) P(X ≥ 1)? (c) E(X)?

Show solution

4 independent trials with success chance 1/3: X ~ B(4, 1/3).

(a) C(4, 2) (1/3)² (2/3)² = 6 × 1/9 × 4/9 = 8/27 ≈ 0.2963.

(b) 1 − P(X = 0) = 1 − (2/3)⁴ = 1 − 16/81 = 65/81 ≈ 0.8025.

(c) E(X) = np = 4/3 ≈ 1.333.

B3

First basket

Standard

A player scores a shot with chance 0.2, each shot independent. X = number of shots until the first basket (included).

(a) P(X = 3)? (b) E(X)? (c) P(X > 4)?

Show solution

X ~ G(0.2).

(a) Two misses then a basket: 0.8² × 0.2 = 0.128.

(b) E(X) = 1/p = 5 shots.

(c) The first 4 shots all miss: 0.8⁴ = 0.4096.

B4

Faulty bulbs

Standard

A box holds 10 bulbs, 3 of them faulty. You take 4 bulbs at once (no putting back). X = number of faulty bulbs taken.

(a) P(X = 1)? (b) E(X)?

Show solution

X ~ H(N = 10, n = 4, N_A = 3).

(a) C(3, 1) × C(7, 3) / C(10, 4) = 3 × 35 / 210 = 1/2.

(b) E(X) = n N_A / N = 4 × 3/10 = 1.2.

B5

Typos

Standard

A book has on average 3 typos per page, and the number of typos on a page follows a Poisson law.

(a) Chance a page has no typo? (b) Chance it has at most 1? (c) Parameter λ for the number of typos on 2 pages?

Show solution

X ~ P(3).

(a) e⁻³ ≈ 0.0498.

(b) e⁻³ + 3e⁻³ = 4e⁻³ ≈ 0.1991.

(c) Two independent pages: P(3) + P(3) = P(6), so λ = 6.

B6

Rare defects

Challenge

A machine makes 200 parts; each is defective with chance 0.01, independently. Use the Poisson approximation.

(a) Which λ? (b) Approximate chance of no defective part.

Show solution

X ~ B(200, 0.01), with n ≥ 30 and p < 0.1: X ≈ P(np).

(a) λ = 200 × 0.01 = 2.

(b) P(X = 0) ≈ e⁻² ≈ 0.1353. The exact binomial value 0.99²⁰⁰ ≈ 0.1340 is very close (and is accepted too).

B7

Poisson variance

Warm-up

X follows a Poisson law with E(X) = 4. What is Var(X)?

Show solution

For a Poisson law the mean and the variance are the same number λ: Var(X) = 4.

B8

A raffle

Warm-up

A ticket is drawn at random among tickets numbered 1 to 10. X = its number. Compute E(X) and Var(X).

Show solution

X ~ U{1, …, 10}.

E(X) = (n + 1)/2 = 5.5. Var(X) = (n² − 1)/12 = 99/12 = 8.25.

Uniform on [2, 8]

Warm-up

X ~ U[2, 8]. Compute (a) E(X), (b) Var(X), (c) P(X > 6).

Show solution

C2

A component's life

Standard

A component's life X (years) is exponential with mean 4 years. Find (a) θ, (b) P(X > 4), (c) P(X ≤ 2).

X ~ E(θ): F(x) = 1 − e^(−θx), E(X) = 1/θ
Show solution

(a) E(X) = 1/θ = 4, so θ = 0.25.

(b) P(X > x) = e^{−θx}: e^{−1} ≈ 0.3679.

(c) 1 − e^{−0.5} ≈ 0.3935.

C3

Standardising

Standard

X ~ N(50, 25) (variance 25). Compute (a) P(X ≤ 60), (b) P(45 < X < 55), (c) P(X > 57.5).

Table: Φ(1) = 0.8413 · Φ(1.5) = 0.9332 · Φ(2) = 0.9772 · Φ(−u) = 1 − Φ(u)
Show solution

σ = √25 = 5 and U = (X − 50)/5 ~ N(0, 1).

(a) Φ((60 − 50)/5) = Φ(2) = 0.9772.

(b) Φ(1) − Φ(−1) = 2Φ(1) − 1 = 2 × 0.8413 − 1 = 0.6826.

(c) 1 − Φ(1.5) = 1 − 0.9332 = 0.0668.

C4

Which σ?

Warm-up

In the course's notation, X ~ N(10, 4). What is the standard deviation of X?

Show solution

The course writes N(m, σ²): the 2nd number is the variance. σ = √4 = 2.

Careful: some slides write N(m, σ) with σ itself. Always check which one is meant.

C5

Gamma

Standard

(a) Compute Γ(6). (b) X ~ γ(4, 2): compute E(X) and (c) Var(X).

Show solution

(a) Γ(n) = (n − 1)!: Γ(6) = 5! = 120.

(b) α/β = 4/2 = 2. (c) α/β² = 4/4 = 1.

C6

χ², Student, Fisher

Standard

Compute (a) E and (b) Var of χ²₆, (c) the variance of Student t₆, (d) the mean of Fisher F(3, 8).

Show solution

(a) n = 6. (b) 2n = 12.

(c) n/(n − 2) = 6/4 = 1.5.

(d) n₂/(n₂ − 2) = 8/6 = 4/3 ≈ 1.333.

C7

Sum of normals

Standard

X ~ N(1, 9) and Y ~ N(2, 16) are independent (2nd number = variance). What is the law of X + Y?

Show solution

Means add: 1 + 2 = 3. Variances add: 9 + 16 = 25. So X + Y ~ N(3, 25), σ = 5.

N(3, 7) adds the σ's (3 + 4), a common mistake.

C8

Stable sums

Challenge

(a) X₁ ~ P(1.5) and X₂ ~ P(2.5) are independent. P(X₁ + X₂ = 0)? (b) Y₁ ~ B(3, 1/2) and Y₂ ~ B(5, 1/2) are independent. P(Y₁ + Y₂ = 4)?

Show solution

(a) X₁ + X₂ ~ P(4): P(0) = e⁻⁴ ≈ 0.0183.

(b) Same p, so Y₁ + Y₂ ~ B(8, 1/2): C(8, 4)/2⁸ = 70/256 = 35/128 ≈ 0.2734.
