What a random variable is (variable aléatoire réelle)

↑ contents
In plain words

An experiment gives a result ω (a face, a card, a person). Often we only care about a number attached to that result: the gain in a game, the number of sixes, a height. A random variable X is just that rule: “result ω → number X(ω)”.

One condition: for every value x, the set of results that give x, written X⁻¹(x), must be an event, meaning a set the probability P knows how to measure. Otherwise we could not ask “what is the chance that X = x?”.

  • Probability space (Ω, B, P) (espace de probabilité)Ω = all possible results; B = the family of events (sets of results that get a probability); P = the probability. Reminder from Chapter 0.
  • Random variable X (variable aléatoire (v.a.))A function X : Ω → E ⊆ ℝ such that X⁻¹(x) is in B for every x.the gain in a dice game
  • X⁻¹(x) (image réciproque)Read “the results sent to x”: {ω ∈ Ω : X(ω) = x}. It goes backwards, from the value to the results.X⁻¹(1) = {a, d}
  • X(Ω)The set of values X can take.{0, 1}
  • Discrete variable (variable aléatoire discrète, VAD)X(Ω) is countable: you can number its values one by one (finite, ℕ or ℤ).a count, a face
  • Continuous variable (variable aléatoire continue)X(Ω) is a whole interval of ℝ, like a time or a length.a waiting time
Worked example
  • Example 1 (course). Ω = {a, b, c, d}, every subset is an event (B = P(Ω), all subsets). X(a) = X(d) = 1 and X(b) = X(c) = 0.
  • X(Ω) = {0, 1}. X⁻¹(0) = {b, c} and X⁻¹(1) = {a, d}. Both are subsets of Ω, so both are events: X is a random variable, and a discrete one.
  • Example 2 (course). Same Ω and same X, but now the events are only B = {∅, {a}, {b}, {c, d}, {a, b}, {a, c, d}, {b, c, d}, Ω}.
  • X⁻¹(0) = {b, c} is not in this list, so P({b, c}) is not defined and “P(X = 0)” makes no sense: here X is not a random variable.

The law of a discrete variable (loi de probabilité d'une VAD)

↑ contents
In plain words

The law of X is the list of its values with the chance of each one. For a discrete X it fits in a two-row table: values on top, chances below.

To fill the table, go back to the results: P(X = x) is the probability of the set of results that give x. The chances in the table always add up to 1.

  • Law of X (loi de probabilité)The numbers P(X = x) = P(X⁻¹(x)) for every x in X(Ω).
  • CheckΣ P(X = x) over all values = 1.
  • Certain variable (variable certaine)X always equals the same number a: P(X = a) = 1. (Also called the Dirac law at a.)X = 5 whatever happens
  • Indicator of A (variable indicatrice, I_A)X = 1 if the result is in A, 0 otherwise. P(X = 1) = P(A), P(X = 0) = 1 − P(A).1 if the die is even
Worked example
  • Example 1 (course). Throw a fair die, X = the face. X(Ω) = {1, …, 6} and P(X = k) = 1/6 for each k.
  • Example 2 (course): a dice game. Throw a fair die. You win 10 DA if the face is even, win 20 DA on a 1 or a 3, and lose 10 DA on a 5. X = your gain.
  • Values: X(Ω) = {−10, 10, 20}. Go back to the faces: X⁻¹(−10) = {5}, X⁻¹(10) = {2, 4, 6}, X⁻¹(20) = {1, 3}.
  • Chances: P(X = −10) = 1/6, P(X = 10) = 3/6 = 1/2, P(X = 20) = 2/6 = 1/3. Check: 1/6 + 3/6 + 2/6 = 1.

The distribution function F (fonction de répartition)

↑ contents
In plain words

F(x) answers one question for every number x: what is the chance that X is at most x? It collects all the probability sitting at x or to its left.

For a discrete X the graph is a staircase: flat between two values, with a jump at each value equal to its chance. From F you can get the chance of any interval, but watch the ends: “<” and “≤” are not the same when X has a jump there.

  • F(x) (fonction de répartition)F(x) = P(X ≤ x). For a discrete X: F(x) = sum of P(X = xᵢ) over the values xᵢ ≤ x.
  • Properties0 ≤ F(x) ≤ 1; F never goes down (increasing, croissante); F → 0 far left and F → 1 far right.
  • Interval ]a, b]P(a < X ≤ b) = F(b) − F(a). This one has no correction.
  • Interval [a, b]P(a ≤ X ≤ b) = F(b) − F(a) + P(X = a): add back the jump at a.
  • Interval [a, b[P(a ≤ X < b) = F(b) − F(a) − P(X = b) + P(X = a).
  • Interval ]a, b[P(a < X < b) = F(b) − F(a) − P(X = b).
  • Other conventionSome slides (Boussaha) define F(x) = P(X < x) instead. Same idea, but the jump values move to the other side. This course uses ≤.
Worked example
  • Example (course). Fair die, X = the face, P(X = k) = 1/6.
  • F(x) = 0 for x < 1, 1/6 on [1, 2[, 1/3 on [2, 3[, 1/2 on [3, 4[, 2/3 on [4, 5[, 5/6 on [5, 6[, and 1 for x ≥ 6.
  • Same interval, four ends (our check). P(2 < X ≤ 4) = F(4) − F(2) = 4/6 − 2/6 = 1/3 (faces 3, 4).
  • P(2 ≤ X ≤ 4) = 1/3 + P(X = 2) = 1/2 (faces 2, 3, 4). P(2 ≤ X < 4) = 1/3 − 1/6 + 1/6 = 1/3 (faces 2, 3). P(2 < X < 4) = 1/3 − 1/6 = 1/6 (face 3).

Expectation (espérance mathématique)

↑ contents
In plain words

The expectation E(X) is the average value of X if you repeat the experiment a very large number of times. Each value counts in proportion to its chance.

Picture the bars of the law on a ruler: E(X) is the point where the ruler balances. The transfer theorem says: to get the mean of g(X), you do not need the law of g(X), just apply g to each value and keep the same chances.

  • E(X) (espérance)E(X) = Σ xᵢ P(X = xᵢ). If all n values are equally likely, it is the plain average (x₁ + … + xₙ)/n.
  • Linearity (linéarité)E(a) = a; E(X + a) = E(X) + a; E(aX) = a E(X); E(X + Y) = E(X) + E(Y).E(2X + 3) = 2E(X) + 3
  • Transfer theorem (théorème de transfert)E(g(X)) = Σ g(xᵢ) P(X = xᵢ).E(X²) = Σ xᵢ² P(X = xᵢ)
Worked example
E(X) = Σ xᵢ P(X = xᵢ) E(g(X)) = Σ g(xᵢ) P(X = xᵢ)
  • Example (course): the dice game. Throw a fair die; win 10 DA on an even face, win 20 DA on 1 or 3, lose 10 DA on 5. Law: P(X = −10) = 1/6, P(X = 10) = 1/2, P(X = 20) = 1/3.
  • E(X) = (−10) × 1/6 + 10 × 1/2 + 20 × 1/3 = (−10 + 30 + 40)/6 = 10. On average you win 10 DA per throw.
  • Transfer (ours). E(X²) = 100 × 1/6 + 100 × 1/2 + 400 × 1/3 = (100 + 300 + 800)/6 = 200. No need to find the law of X² first.
  • Linearity (ours). If the prize is doubled and 3 DA added: E(2X + 3) = 2 × 10 + 3 = 23.

Variance and standard deviation (variance, écart-type)

↑ contents
In plain words

Two variables can have the same mean and still behave very differently: one stays close to its mean, the other jumps far away. The variance measures that spread: the average of the squared distance to the mean.

Because it squares distances, the variance is in “units squared”. Its square root, the standard deviation σ, is back in the units of X.

  • Var(X) (variance)Var(X) = Σ (xᵢ − E(X))² P(X = xᵢ) = E[(X − E(X))²].
  • Shortcut (König)Var(X) = E(X²) − (E(X))². Usually the fastest way.
  • PropertiesVar(X) ≥ 0; Var(X) = 0 only if X is constant; Var(X + a) = Var(X) (shifting does not spread); Var(aX) = a² Var(X).Var(2X + 3) = 4 Var(X)
  • Standard deviation σ (écart-type)σ(X) = √Var(X).
Worked example
Var(X) = E(X²) − (E(X))² Var(aX + b) = a² Var(X)
  • Example (course). X takes 2, 4, 6 with chances 1/4, 1/4, 1/2. Y takes −4, 3, 33 with chances 1/2, 1/3, 1/6.
  • Means: E(X) = 2/4 + 4/4 + 6/2 = 9/2. E(Y) = −4/2 + 3/3 + 33/6 = 9/2. Same mean, 4.5.
  • E(X²) = 4/4 + 16/4 + 36/2 = 23, so Var(X) = 23 − (9/2)² = 23 − 81/4 = 11/4 (σ ≈ 1.66).
  • E(Y²) = 16/2 + 9/3 + 1089/6 = 385/2, so Var(Y) = 385/2 − 81/4 = 689/4 (σ ≈ 13.12). Y is far more spread out.
  • Dice game (ours). E(X) = 10 and E(X²) = 200, so Var(X) = 200 − 100 = 100 and σ = 10. Then Var(2X + 3) = 4 × 100 = 400.

Moments and the generating function (moments, fonction génératrice des moments)

↑ contents
In plain words

Moments are the averages of the powers of X. The 1st moment is the mean, the 2nd centred moment is the variance. Higher ones describe the shape: the 3rd centred moment is negative when the long tail is on the left.

The moment generating function (from the handwritten summary) packs all the moments into one function M(t). Its slope at t = 0 gives E(X), its second derivative at 0 gives E(X²).

  • Raw moment of order r (moment non centré)M_r(X) = E(X^r) = Σ xᵢ^r P(X = xᵢ).M₁ = E(X)
  • Centred moment of order r (moment centré)μ_r(X) = E[(X − E(X))^r]. Always μ₁ = 0 and μ₂ = Var(X).
  • Variance from momentsVar(X) = M₂ − M₁².
  • MGF (fonction génératrice des moments)M_X(t) = E(e^{tX}). Then M′_X(0) = E(X), M″_X(0) = E(X²), and the r-th derivative at 0 is E(X^r).
  • Useful MGFsBernoulli: 1 − p + p eᵗ. Binomial B(n, p): (p eᵗ + 1 − p)ⁿ. Poisson P(λ): e^{λ(eᵗ − 1)}.
Worked example
  • Dice game (ours). Values −10, 10, 20 with chances 1/6, 1/2, 1/3, mean 10.
  • Third centred moment: μ₃ = (−20)³ × 1/6 + 0³ × 1/2 + 10³ × 1/3 = −8000/6 + 1000/3 = −1000. Negative: the lone loss (−10) pulls a tail to the left.
  • Bernoulli MGF (summary). X = 1 with chance p, 0 with chance 1 − p. M(t) = e^{0·t}(1 − p) + e^{1·t} p = 1 − p + p eᵗ.
  • M′(t) = p eᵗ, so M′(0) = p = E(X). M″(0) = p = E(X²), so Var(X) = p − p² = p(1 − p).

Continuous variables and density (variable absolument continue, densité de probabilité)

↑ contents
In plain words

A continuous X (a time, a length) can take every value of an interval. The chance of one exact value is 0: the chance of a bus coming at exactly 8:00:00.000… is nothing. Only intervals get a chance.

The density f is a curve whose area gives the chance: P(a ≤ X ≤ b) = area under f between a and b. A density is never negative and its total area is 1. And since single points weigh 0, it does not matter here whether the ends are “<” or “≤”.

  • Absolutely continuous (absolument continue)F is continuous (no jumps) and has a derivative from the left and from the right.
  • Density f (densité de probabilité)The derivative of F: F(x) = ∫₋∞ˣ f(t) dt.
  • Rulesf(x) ≥ 0 everywhere; ∫ f = 1 over ℝ. Any function with these two properties is a density.
  • ChancesP(X = x) = 0, and P(a ≤ X ≤ b) = P(a < X < b) = F(b) − F(a) = ∫ₐᵇ f(x) dx.
Worked example
  • Example (course). X has density f(x) = a e^{−2x} for x > 0 and 0 otherwise. Find a, then F.
  • f ≥ 0 forces a ≥ 0. Total area = 1: ∫₀^∞ a e^{−2x} dx = a × 1/2 = 1, so a = 2.
  • F(x) = 0 for x ≤ 0, and for x ≥ 0: F(x) = ∫₀ˣ 2e^{−2t} dt = 1 − e^{−2x}.
  • Use it (ours). P(X ≤ 1) = F(1) = 1 − e⁻² ≈ 0.865. P(X > 0.5) = 1 − F(0.5) = e⁻¹ ≈ 0.368.

Mean and variance with integrals (moments d'une VAR absolument continue)

↑ contents
In plain words

Everything from Part A carries over: just replace the sum Σ by an integral ∫ and the chances P(X = xᵢ) by f(x) dx.

Same linearity, same transfer theorem, same shortcut Var(X) = E(X²) − (E(X))².

  • E(X) (espérance)E(X) = ∫ x f(x) dx over ℝ.
  • Transfer theorem (théorème de transfert)E(g(X)) = ∫ g(x) f(x) dx.
  • Var(X) (variance)Var(X) = ∫ (x − E(X))² f(x) dx = E(X²) − (E(X))².
  • MomentsM_r = ∫ x^r f(x) dx and μ_r = ∫ (x − E(X))^r f(x) dx, with μ₁ = 0 and μ₂ = Var(X).
Worked example
E(X) = ∫ x f(x) dx E(X²) = ∫ x² f(x) dx
  • Example (ours, with the course's density). f(x) = 2e^{−2x} for x > 0.
  • E(X) = ∫₀^∞ x · 2e^{−2x} dx. Integrate by parts: = 1/2.
  • E(X²) = ∫₀^∞ x² · 2e^{−2x} dx = 2/4 = 1/2, so Var(X) = 1/2 − 1/4 = 1/4 and σ = 1/2.
  • This is the exponential law with θ = 2 (section 17): mean 1/θ, variance 1/θ².

A function of a variable: Y = g(X) (loi d'une fonction d'une v.a.)

↑ contents
In plain words

Often we know the law of X and want the law of a new variable Y = g(X), like the area of a square whose side X is random.

Safe method (from the handwritten summary): first find F_Y by turning “Y ≤ y” into a condition on X, then differentiate to get the density f_Y. Never transform the density directly.

  • Step 1F_Y(y) = P(Y ≤ y) = P(g(X) ≤ y): solve for X.
  • Step 2f_Y(y) = F_Y′(y).
  • Linear caseY = aX + b with a > 0: F_Y(y) = F_X((y − b)/a) and f_Y(y) = f_X((y − b)/a) / a.
Worked example
  • Example A (ours). X uniform on [0, 1] (density 1 there), Y = X². Y lives in [0, 1].
  • F_Y(y) = P(X² ≤ y) = P(X ≤ √y) = √y for y in [0, 1]. So f_Y(y) = 1/(2√y).
  • Check: P(Y ≤ 0.25) = √0.25 = 0.5. Of course: X² ≤ 0.25 exactly when X ≤ 0.5.
  • Example B (ours). Same X, Y = 2X + 1. F_Y(y) = P(X ≤ (y − 1)/2) = (y − 1)/2 on [1, 3], so f_Y = 1/2 there: Y is uniform on [1, 3].

Discrete uniform law (loi uniforme discrète)

↑ contents
In plain words

n values, all equally likely: each gets 1/n. A fair die is the classic case.

Its mean is the ordinary average of the values.

  • X ~ U{x₁, …, xₙ} (loi uniforme discrète)P(X = xᵢ) = 1/n for each i.
  • Mean, varianceE(X) = x̄ = (x₁ + … + xₙ)/n; Var(X) = (1/n) Σ xᵢ² − x̄².
  • On {1, …, n}E(X) = (n + 1)/2; Var(X) = (n² − 1)/12.die: 7/2 and 35/12
  • On {a, …, b} (slides)P(X = x) = 1/(b − a + 1); E(X) = (a + b)/2; Var(X) = ((b − a + 1)² − 1)/12.
Worked example
  • Example (course). An urn holds n balls numbered 1 to n. Draw one; X = its number. Each number has chance 1/n, so X ~ U{1, …, n}.
  • E(X) = (1 + 2 + … + n)/n = n(n + 1)/(2n) = (n + 1)/2. E(X²) = (n + 1)(2n + 1)/6, so Var(X) = (n² − 1)/12.
  • Fair die, n = 6: E(X) = 7/2 = 3.5, Var(X) = 35/12 ≈ 2.92.
  • Values 3 to 8 (ours). 6 values: E(X) = (3 + 8)/2 = 5.5, Var(X) = (6² − 1)/12 = 35/12. Same spread as the die: shifting does not change the variance.

Bernoulli law (loi de Bernoulli)

↑ contents
In plain words

One trial with two outcomes: success (coded 1) with chance p, failure (coded 0) with chance 1 − p. Every yes/no question is a Bernoulli variable.

It is the building block of the next laws: count Bernoulli successes and you get the binomial; wait for the first success and you get the geometric.

  • X ~ B(p) (loi de Bernoulli)X(Ω) = {0, 1}, P(X = 1) = p, P(X = 0) = 1 − p. Short form: P(X = k) = p^k (1 − p)^{1−k}.
  • qShort for 1 − p, the chance of failure.
  • F(x)0 if x < 0; q = 1 − p if 0 ≤ x < 1; 1 if x ≥ 1.
  • Mean, varianceE(X) = p; E(X²) = p; Var(X) = p(1 − p) = pq.
Worked example
  • Example (course). Toss a fair coin; I win on heads. X = 1 on heads, 0 on tails. So X ~ B(1/2).
  • E(X) = 0 × 1/2 + 1 × 1/2 = 1/2. E(X²) = 1/2, so Var(X) = 1/2 − 1/4 = 1/4.
  • Another (course). A survey question answered “yes” (1) or “no” (0) is a Bernoulli variable; p is the share of “yes”.

Binomial law (loi binomiale)

↑ contents
In plain words

Repeat the same Bernoulli trial n times, independently (one trial does not affect the others). X = the number of successes. Then X is binomial B(n, p).

Why C(n, k)? A result with exactly k successes is a choice of which k of the n trials succeed (C(n, k) ways, Chapter 0); each such result has chance p^k (1 − p)^{n−k}.

  • X ~ B(n, p) (loi binomiale)X(Ω) = {0, 1, …, n}; P(X = k) = C(n, k) p^k (1 − p)^{n−k}.
  • Sum of BernoullisX = X₁ + … + Xₙ with Xᵢ ~ B(p) independent. That is how the mean and variance are found.
  • Mean, varianceE(X) = np; Var(X) = np(1 − p).
  • Independent (indépendantes)Knowing the result of some trials does not change the chances of the others.
Worked example
P(X = k) = C(n, k) p^k (1 − p)^(n − k)
  • Example (course). Throw a fair die 5 times; X = the number of 1s. Each throw is a Bernoulli trial with p = 1/6, and the throws are independent, so X ~ B(5, 1/6).
  • P(X = k) = C(5, k) (1/6)^k (5/6)^{5−k}. E(X) = 5/6 ≈ 0.83, Var(X) = 5 × 1/6 × 5/6 = 25/36.
  • Use it (ours). P(X = 2) = C(5, 2) × (1/6)² × (5/6)³ = 10 × 1/36 × 125/216 = 625/3888 ≈ 0.161.
  • At least one 1: P(X ≥ 1) = 1 − P(X = 0) = 1 − (5/6)⁵ = 4651/7776 ≈ 0.598.

Geometric law (loi géométrique)

↑ contents
In plain words

Repeat a Bernoulli trial until the first success. X = the number of trials it took (the success included). Unlike the binomial, the number of trials is not fixed in advance.

X = k means k − 1 failures then one success, which has chance (1 − p)^{k−1} p.

  • X ~ G(p) (loi géométrique)X(Ω) = {1, 2, 3, …}; P(X = k) = (1 − p)^{k−1} p.
  • Mean, varianceE(X) = 1/p; Var(X) = (1 − p)/p².p = 1/6: wait 6 throws on average
  • TailP(X > k) = (1 − p)^k: the first k trials all failed.
  • Negative binomial (slides) (loi binomiale négative)Wait for the n-th success instead of the first: mean n/p, variance n(1 − p)/p².
Worked example
  • Example (course). An urn has a share p of white balls. Draw with replacement (put the ball back) until the first white; X = number of draws. The draws are independent with the same p, so X ~ G(p) and P(X = k) = p(1 − p)^{k−1}.
  • With numbers (ours). Throw a fair die until the first six: p = 1/6.
  • P(X = 3) = (5/6)² × 1/6 = 25/216 ≈ 0.116. E(X) = 1/p = 6. Var(X) = (5/6)/(1/36) = 30.
  • No six in the first 3 throws: P(X > 3) = (5/6)³ = 125/216 ≈ 0.579.

Hypergeometric law (loi hypergéométrique)

↑ contents
In plain words

Like the binomial, but the draws are made without putting back, so the urn changes after each draw and the draws are not independent.

Count with combinations (Chapter 0): choose x objects among the N_A “good” ones and n − x among the others, out of all C(N, n) samples.

  • X ~ H(N, n, N_A) (loi hypergéométrique)Urn of N objects, N_A of type A. Draw n without replacement; X = number of type A drawn.
  • LawP(X = x) = C(N_A, x) C(N − N_A, n − x) / C(N, n), for max{0, n − (N − N_A)} ≤ x ≤ min{n, N_A}.
  • Mean, varianceE(X) = n N_A/N; Var(X) = n × (N − n)/(N − 1) × N_A/N × (1 − N_A/N).
  • Link with binomialSame mean as B(n, N_A/N); the variance has the extra factor (N − n)/(N − 1) < 1.
Worked example
  • Example (ours). An urn has N = 20 balls: N_A = 4 black, 16 white. Draw n = 3 without putting back; X = number of black balls.
  • C(20, 3) = 1140 samples. P(X = 0) = C(16, 3)/1140 = 560/1140 = 28/57 ≈ 0.491. P(X = 1) = 4 × 120/1140 = 8/19 ≈ 0.421.
  • P(X = 2) = 6 × 16/1140 = 8/95 ≈ 0.084. P(X = 3) = 4/1140 = 1/285 ≈ 0.004. Sum: 1.
  • E(X) = 3 × 4/20 = 3/5. Var(X) = 3 × 17/19 × 1/5 × 4/5 = 204/475 ≈ 0.43.

Poisson law (loi de Poisson)

↑ contents
In plain words

The Poisson law counts how many times a rare event happens in a fixed period: breakdowns per month, clients per hour, typos per page. Its only parameter λ is the average count.

It appears when you have many chances for the event, each very small: B(n, p) with n large and p small is close to Poisson with λ = np.

  • X ~ P(λ) (loi de Poisson)X(Ω) = ℕ = {0, 1, 2, …}; P(X = k) = e^{−λ} λ^k / k!.
  • Mean, varianceE(X) = λ and Var(X) = λ (the same number).
  • Poisson approximation (approximation)If n ≥ 30 and p < 0.1 (summary's rule), B(n, p) ≈ P(np).
  • SumX₁ ~ P(λ₁), X₂ ~ P(λ₂) independent ⇒ X₁ + X₂ ~ P(λ₁ + λ₂).
Worked example
P(X = k) = e^(−λ) λ^k / k!
  • Example (course). A machine breaks down 2 times a month on average; X = breakdowns in a month, assumed Poisson. Since E(X) = λ, λ = 2.
  • 1. No breakdown: P(X = 0) = e⁻² × 2⁰/0! = e⁻² ≈ 0.135 (recall 0! = 1).
  • 2. At least two: P(X ≥ 2) = 1 − P(X = 0) − P(X = 1) = 1 − e⁻² − 2e⁻² = 1 − 3e⁻² ≈ 0.594.
  • Example (slides). 15 clients per hour on average arrive at a counter, independently. P(exactly 20 in an hour) = e⁻¹⁵ × 15²⁰/20! ≈ 0.0418, about 4.2%.

Continuous uniform law (loi uniforme continue)

↑ contents
In plain words

X falls “anywhere” in [a, b] with no preferred place: the density is flat. The chance of a piece of the interval is just its length divided by b − a.

The mean is the middle of the interval.

  • X ~ U[a, b] (loi uniforme continue)f(x) = 1/(b − a) on [a, b], 0 outside.
  • F(x)0 if x < a; (x − a)/(b − a) on [a, b[; 1 if x ≥ b.
  • Mean, varianceE(X) = (a + b)/2; Var(X) = (b − a)²/12.
Worked example
  • Example (ours). A bus passes every 10 minutes; you arrive at a random time. X = waiting time in minutes ~ U[0, 10].
  • E(X) = (0 + 10)/2 = 5 min. Var(X) = 10²/12 = 25/3 ≈ 8.33, σ ≈ 2.89 min.
  • P(2 < X < 5) = (5 − 2)/10 = 0.3.
  • U[2, 6]: E(X) = 4, Var(X) = 16/12 = 4/3, and P(X ≤ 3) = (3 − 2)/4 = 1/4.

Exponential law (loi exponentielle)

↑ contents
In plain words

The exponential law models a lifetime or a waiting time: how long a lamp lasts, how long until the next client. Short times are the most likely; long ones become rarer and rarer.

θ is a rate (events per unit of time); the mean lifetime is 1/θ.

  • X ~ E(θ) (loi exponentielle)f(x) = θ e^{−θx} for x ≥ 0, 0 otherwise (θ > 0).
  • F(x)F(x) = 1 − e^{−θx} for x ≥ 0. So P(X > x) = e^{−θx}.
  • Mean, varianceE(X) = 1/θ; Var(X) = 1/θ².
  • Lifetime (durée de vie)The course's typical uses: life of a device, length of unemployment, length of a hospital stay.
Worked example
  • Example (ours). A lamp's life X in years follows E(0.5), so θ = 0.5.
  • E(X) = 1/0.5 = 2 years; Var(X) = 1/0.25 = 4, σ = 2.
  • P(lasts more than 3 years) = e^{−0.5 × 3} = e^{−1.5} ≈ 0.223.
  • P(dies within 2 years) = 1 − e^{−1} ≈ 0.632.
  • Course density. f(x) = 2e^{−2x} of section 7 is E(2): mean 1/2, variance 1/4.

Normal law (loi normale, loi de Laplace-Gauss)

↑ contents
In plain words

The bell curve: values pile up around the mean m and thin out symmetrically on both sides. Heights, measurement errors and many sums of small effects look like this.

There is no formula for its area, so we use a table of Φ, the distribution function of the standard bell N(0, 1). Any normal X is brought back to it by standardising: U = (X − m)/σ.

  • X ~ N(m, σ²) (loi normale)f(x) = e^{−(x − m)²/(2σ²)} / (σ√(2π)). The 2nd number is the variance σ².N(3, 9): σ = 3
  • Mean, varianceE(X) = m, Var(X) = σ².
  • Standard normal (loi normale centrée réduite)U = (X − m)/σ ~ N(0, 1), density φ(u) = e^{−u²/2}/√(2π).
  • Φ (fonction de répartition de N(0, 1))Φ(u) = P(U ≤ u), read in the table for u ≥ 0. For negatives: Φ(−u) = 1 − Φ(u).Φ(1) = 0.8413
  • Reading FF_X(x) = Φ((x − m)/σ).
  • 68 – 95 – 99.7About 68.3% of values within m ± σ, 95.4% within m ± 2σ, 99.7% within m ± 3σ. Also P(|U| ≤ 1.96) = 0.95.
Worked example
U = (X − m)/σ ~ N(0, 1) F_X(x) = Φ((x − m)/σ) Φ(−u) = 1 − Φ(u)
  • Example (course). X ~ N(3, 9), so m = 3 and σ = √9 = 3.
  • F(6) = Φ((6 − 3)/3) = Φ(1) = 0.8413.
  • P(2 < X ≤ 4) = Φ(1/3) − Φ(−1/3) = 2Φ(0.33) − 1 = 2 × 0.6293 − 1 = 0.2586.
  • P(X > 0) = 1 − Φ(−1) = Φ(1) = 0.8413.
  • P(|X − 3| > 6) = P(|U| > 2) = 2(1 − Φ(2)) = 2 × (1 − 0.9772) = 0.0456.
  • Heights (ours). X ~ N(170, 10²) in cm. P(X ≤ 180) = Φ(1) = 0.8413. P(160 < X < 190) = Φ(2) − Φ(−1) = 0.9772 − 0.1587 = 0.8186.
  • Sum (summary). X ~ N(1, 4) and Y ~ N(2, 5) independent: X + Y ~ N(1 + 2, 4 + 5) = N(3, 9). Means add and variances add (not the σ's).

Gamma law (loi Gamma)

↑ contents
In plain words

The gamma law is a family of lifetime-type laws with a shape α and a rate β. With α = 1 it is exactly the exponential law. Adding up n independent exponential waiting times gives a gamma with α = n.

Its formula uses Euler's Γ function, a smooth version of the factorial: Γ(n) = (n − 1)!.

  • Γ(α) (fonction Gamma d'Euler)Γ(α) = ∫₀^∞ e^{−t} t^{α−1} dt.
  • Γ propertiesΓ(α + 1) = α Γ(α); Γ(1) = 1; Γ(n) = (n − 1)!; Γ(1/2) = √π.Γ(5) = 4! = 24
  • X ~ γ(α, β) (loi Gamma)f(x) = β^α e^{−βx} x^{α−1} / Γ(α) for x ≥ 0.
  • Mean, varianceE(X) = α/β; Var(X) = α/β².
  • Special casesγ(1, β) = E(β), the exponential law with parameter β. γ(n/2, 1/2) = χ²ₙ.
  • SumsX₁, …, Xₙ independent E(λ) ⇒ X₁ + … + Xₙ ~ γ(n, λ). γ(p, θ) + γ(q, θ) independent ~ γ(p + q, θ).
Worked example
  • Γ values. Γ(5) = 4! = 24. Γ(3/2) = (1/2) Γ(1/2) = √π/2 ≈ 0.886.
  • Example (ours). X ~ γ(2, 0.5): E(X) = 2/0.5 = 4, Var(X) = 2/0.25 = 8. (It is also χ²₄, see section 20.)
  • Y ~ γ(3, 2): E(Y) = 3/2, Var(Y) = 3/4.
  • Sum (ours). Three independent waiting times, each E(2): their total is γ(3, 2), mean 3 × 1/2 = 3/2.

Chi-square, Student and Fisher (lois du Khi-deux, de Student, de Fisher-Snedecor)

↑ contents
In plain words

These three laws are built from standard normals. They are not used to model data directly but to test and estimate in statistics (next chapters), so you mostly read them in tables.

The number n is the degrees of freedom (degrés de liberté, d.d.l.): roughly, how many independent squared normals went into the variable.

  • χ²ₙ (loi du Khi-deux)U₁, …, Uₙ independent N(0, 1) ⇒ U₁² + … + Uₙ² ~ χ²ₙ. Not symmetric; only positive values.U² ~ χ²₁
  • χ² mean, varianceE = n, Var = 2n. And χ²ₙ = γ(n/2, 1/2).
  • χ² sumχ²ₙ₁ + χ²ₙ₂ independent ~ χ²ₙ₁₊ₙ₂.
  • Student tₙ (loi de Student)U ~ N(0, 1), Y ~ χ²ₙ independent ⇒ T = U / √(Y/n) ~ tₙ. Symmetric around 0, like the bell but with fatter tails.
  • Student mean, varianceE = 0 (n > 1); Var = n/(n − 2) (n > 2).
  • Fisher F(n₁, n₂) (loi de Fisher-Snedecor)X₁ ~ χ²ₙ₁, X₂ ~ χ²ₙ₂ independent ⇒ (X₁/n₁)/(X₂/n₂) ~ F(n₁, n₂).
  • Fisher mean, varianceE = n₂/(n₂ − 2) (n₂ > 2); Var = 2n₂²(n₁ + n₂ − 2) / [n₁(n₂ − 2)²(n₂ − 4)] (n₂ > 4).
Worked example
  • χ² (ours). χ²₄: E = 4, Var = 8. χ²₁₀: E = 10, Var = 20.
  • Student (ours). t₅: Var = 5/3 ≈ 1.67. t₁₀: Var = 10/8 = 1.25: as n grows the variance goes to 1, the variance of N(0, 1).
  • Fisher (ours). F(4, 10): E = 10/8 = 5/4; Var = 2 × 100 × 12 / (4 × 64 × 6) = 2400/1536 = 25/16.
  • F(5, 12): E = 12/10 = 6/5. The mean depends only on n₂.

Sums of independent variables, and the whole catalogue (stabilité, résumé des lois)

↑ contents
In plain words

Many laws are stable under addition: add two independent variables of the same family and you stay in the family, with the parameters added. This is a big time saver.

The conditions matter: the variables must be independent, and for binomial and gamma the second parameter (p or θ) must be the same.

  • Stable family (stabilité par addition)X₁ + X₂ has a law of the same family as X₁ and X₂.
  • Mean of a sumE(X₁ + X₂) = E(X₁) + E(X₂), always (independent or not).
  • Variance of a sumVar(X₁ + X₂) = Var(X₁) + Var(X₂) when X₁ and X₂ are independent.
